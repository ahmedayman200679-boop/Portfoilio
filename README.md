## 🚀 Quick Preview (Instant)

Because this portfolio is built with standalone **HTML5, Tailwind CSS, and vanilla JavaScript**, there are zero build steps, zero node_modules, and zero dependencies to install!

### Option 1: Direct Double Click
Simply double-click `index.html` in File Explorer or open it in Google Chrome / Microsoft Edge.

### Option 2: Local HTTP Server (Python)
In PowerShell or terminal:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

## 🌐 Free 1-Click Hosting & Deployment

### 1. GitHub Pages (Free with your GitHub account)
1. Push this folder to a GitHub repository named `portfolio` or `ahmedayman200679-boop.github.io`.
2. Go to **Settings** > **Pages** in your repository.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Your site will be live instantly at `https://ahmedayman200679-boop.github.io`!

### 2. Vercel or Netlify (Free drag & drop)
- Go to [Netlify Drop](https://app.netlify.com/drop) and drag the `ahmed-ayman-portfolio` folder directly into the window. It deploys in 10 seconds.
